## 依你圖片處理的重點
- ①②④：過濾股價 5 元以下、5日均量 500 張以下
- ③⑤：圖片明確寫「不要過濾」這兩項，所以本版不過濾
- ②「今日成交量 > 五日均量的20%」先照字面實作成 >20%，不是偷改成 >120%
- ②「30日漲跌幅 <1%」介面可選：
  - |漲跌幅| <1%（盤整）
  - 字面值 <1%
- 五日均量採「今天之前的5個完整交易日」，避免今天同時當分子又進分母
